# Pigify: A Deep Learning-Based Swine Disease and Symptom Monitoring System for Backyard Farms

An AI-powered computer vision and deep learning platform designed for early detection of swine diseases, skin lesions, and symptom monitoring tailored specifically for backyard pig farms.

## Features
- **Skin Lesion & Disease Detection**: Real-time image scanning for swine skin conditions, rashes, erysipelas, and disease symptoms using YOLO object detection models.
- **Backyard Farm Optimization**: Tailored diagnostics and early warning alerts designed for small-scale swine farmers and livestock management.
- **Comprehensive Dashboard**: Track herd health trends, environmental risk factors, and disease analytics over time.
- **Supabase & Cloudinary Integration**: Scalable cloud storage for diagnostic images, diagnostic history, and user authentication.
